Course Description:
This course will provide an overview of state-of-the-art methods for the design of decentralized coordination in groups of communicating
agents, with a focus on mathematical fundamentals and code implementation. A particular emphasis will be placed on nonlinear methods grounded in biological and cognitive principles that
give rise to collectively intelligent behaviors in nature.
